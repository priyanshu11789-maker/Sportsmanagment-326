# 🏆 Sports Management System

A modern, responsive web application to manage sports events, teams, players, tournaments and bookings - all in one place.

Built as a college project for **Lovely Professional University (LPU)** using HTML, CSS & JavaScript.

🔗 **Live Demo:** https://sports-managment-one.vercel.app

---

## ✨ Features

- 🏟️ **Sports & Events Listing** - Browse all sports, tournaments and upcoming events
- 👥 **Team Management** - Create teams, add players, view team details
- 🧑‍🤝‍🧑 **Player Registration** - Register players with details and category
- 📅 **Tournament & Match Schedule** - View fixtures, dates and venues
- 🏆 **Live Scores & Standings** - Track points table and match results
- 📝 **Booking / Join Event** - Users can join tournaments and book slots
- 📱 **Fully Responsive** - Works smoothly on Mobile, Tablet & Desktop
- 🎨 **Modern UI** - Clean design with fast loading on Vercel
